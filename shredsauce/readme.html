!!! READ THIS BEFORE YOU PLAY !!!

If the game doesn’t load, follow these steps:

1) Open a new Chrome window and go to chrome://flags/#enable-npapi
2) Find “Enable NPAPI” highlighted in yellow
3) Click the blue “Enable” button (it will change to “Disable”)
4) A message will appear with “Relaunch Now”
5) Click “Relaunch Now” to restart Chrome
6) After Chrome restarts, try loading Shredsauce again
